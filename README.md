Credit Fraud Data Cleaning And Analysis

Overview

This project focuses on analysing credit card transactions data to identify fraud patterns and provide business recommendations. The analysis includes exploratory data analysis (EDA), visualization and fraud risk insights. 

Objectives

Dataset Cleaning
Compare fraudulent and non-fraudulent transactions
Identify fraud indicators
Analysing Transaction pattern
Provide actionable recommendation

This dataset contains fraud transaction data with following columns

age
transaction_amount  
account_balance 
num_transactions_today 
is_foreign_transaction 
transaction_hour 
prev_fraud_flag 
merchant_distance_km 
merchant_risk_score 
is_fraud   

Tools Used

Python
Pandas
Matplotlib
Seaborn
Jupyter Notebook

Workflow

Load and explore the dataset
Data cleaning, Identified null values, and removed outliers
Perform exploratory data analysis
Created visualization 
Identified fraud pattern
Recommendations

Key Questions Solved:

Percentage of fraud.
Analyse fraud patterns between previous fraud history and foreign transactions.
Is the risk score related to fraud?
Does transaction amount increase risk of fraud?
Relation between transaction amount and risk score.
